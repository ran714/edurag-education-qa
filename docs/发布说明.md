# 1.2.1 发布候选说明

## 功能修复

- 通用知识采用独立提示词，避免没有课程资料时错误输出“信息不足”。
- 课程资料提示词不再包含示例客服电话。
- 显式资料请求和课程价格、退款等事实优先进入检索；原有具体学科范围保持生效。
- 分流结果写入日志，便于区分通用与资料回答。
- 完整服务依赖延迟导入，使离线回归无需 PyTorch、Milvus 和模型权重。

## 发布准备

- 增加 8 条自编 FAQ 及一份 RAG 入门资料；无本地课程 CSV 时可运行示例。
- 增加独立演示验收、Windows/Linux 离线检查工作流及来源说明。
- 发布脚本按白名单创建新候选目录，不复制配置、权重、数据卷或课程原始资料及评测摘录。

## 当前限制

这是本地发布候选，不代表已经发布 GitHub 或通过云端 CI。上游课程代码的来源和许可仍待确认；不能因移除课程资料就宣称拥有全部衍生代码的发布权。

完整模型链路使用当前本机已有环境验证；未宣称在全新环境完成完整模式重装。既有 62 场景与 FAQ 评分属于本地历史证据，源码候选不包含原始题答与评分明细，也不沿用这些分数作为自编示例的效果。
