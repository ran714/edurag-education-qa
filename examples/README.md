# 自编示例数据

这里的 FAQ 和 Markdown 是本轮为软件演示编写的示例，不复制原课程 CSV/PDF，不代表真实课程或用户数据。

- `faq_sample.csv`：8 条 Python / Java 示例问答。
- `knowledge/ai_data/RAG入门.md`：文档入库示例，学科为 `ai`。
- `EDURAG_FAQ_CSV` 可显式指定自己的 CSV；相对路径按项目根目录解析。
- 默认优先使用本机 `mysql_qa/data/*.csv`；源码发布版没有这些文件时使用自编示例。

原课程资料的评测分数不适用于这份示例数据。来源说明见项目根目录的 `THIRD_PARTY_NOTICES.md`。
